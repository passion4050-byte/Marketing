# 네이버 서치어드바이저 고도화 가이드 — wecircle.co.kr

작성: 2026-07-03 (Round 118) · 기준: 서치어드바이저 "URL 실시간 조회결과" 스크린샷

## 1. 현재 상태 진단

조회 결과 7개 항목 중 5개 통과, 2개 경고였다. 사이트 정상 접속(https 308 리다이렉트 인식), robots.txt, 로봇 메타 태그, 사이트 제목, Open Graph 제목은 모두 정상. 경고 2건은 **사이트 설명**과 **Open Graph 설명**이 80자 초과(기존 108자)라는 동일 원인이다.

## 2. 즉시 조치 — 완료 (배포 대기)

두 경고 모두 `medimap-blog/src/lib/site.ts` 의 `siteConfig.description` 한 곳에서 나온다 (layout.tsx 가 meta description 과 og:description 에 같은 값을 사용). 다음과 같이 72자로 축약했다:

> 위서클 — ChatGPT·Gemini·Perplexity 가 병원을 추천하도록 GEO/AEO 콘텐츠를 자동 생성하는 의료 마케팅 SaaS.

브랜드를 선두에 두고 핵심 키워드(GEO/AEO, 의료 마케팅, SaaS)를 유지했다. **push → Vercel Ready 후 서치어드바이저에서 "URL 검색결과" 재조회**하면 두 항목이 ✓ 로 바뀐다. 네이버 검색결과 스니펫 반영은 재수집 후 수일 걸릴 수 있다.

## 3. 스파링 포인트 — 사이트 제목 "WECIRCLE 테크 블로그"

통과 항목이지만 짚는다. `layout.tsx` 의 title 이 `"WECIRCLE 테크 블로그"` 인데, 사이트의 실제 포지셔닝은 의료 마케팅/헬스케어 콘텐츠 채널이다. "테크 블로그"는 (1) 병원·시술 키워드로 유입되는 네이버 사용자와의 관련성 신호를 약화시키고 (2) AI 엔진이 사이트 성격을 분류할 때도 어긋난 힌트를 준다. 후보: "WECIRCLE 인사이트 — 의료 마케팅 & AI 검색" 류. 단, 이미 색인된 타이틀이 바뀌면 일시적 노출 변동이 있으므로 **브랜딩 결정 사항** — 변경 원하면 별도 라운드로.

## 4. 고도화 로드맵 (우선순위순)

### A. RSS 제출 — 미구현, 실질 작업 1순위
현재 사이트에 RSS 라우트가 없다 (Round 117-B 감사에서 확인). 네이버 서치어드바이저는 사이트맵과 별도로 **요청 → RSS 제출** 채널을 운영하며, 네이버 색인에서 RSS 는 여전히 유효한 신호다. `/rss.xml` route handler 를 추가하고(published + compliance pass 필터 재사용, posts + partner posts 통합, 최신 50건) 서치어드바이저에 제출. 예상 작업량: 라우트 1개 + 제출 5분.

### B. 사이트맵 제출 상태 확인
`/sitemap.xml` 은 구현돼 있다 (revalidate 3600). 서치어드바이저 → 요청 → 사이트맵 제출에 wecircle.co.kr 기준으로 등록돼 있는지, 마지막 수집이 성공인지 확인. ⚠️ 함정 DX 이력: 네이버가 특정 사이트맵 형식에 까다로움 — 수집 실패 시 형식부터 의심.

### C. IndexNow — 이미 구현됨, 검증만
Round 82 에서 발행 시 `api.indexnow.org` 자동 핑이 구현돼 있고, 네이버는 IndexNow 를 공식 지원한다 (단일 엔드포인트가 참여 엔진 전체에 전파). 검증 항목 2개: (1) 키 파일이 `https://wecircle.co.kr/{INDEXNOW_KEY}.txt` 에서 200 으로 서빙되는지 (2) scheduler 로그에서 `indexnow.submitted` 가 실제 발행마다 찍히는지. 이게 정상이면 신규 글 수집 요청을 수동으로 할 필요가 없다.

### D. 구조화 데이터
FAQPage JSON-LD 는 Round 81 에서 적용됐다. 확인 항목: 개별 글에 Article(또는 BlogPosting) JSON-LD 가 나가는지 — 없으면 headline/datePublished/author/publisher 필드로 추가. 네이버는 오픈그래프 의존도가 높지만 Article 스키마는 구글·AI 엔진 공용 자산이라 투자 대비 효율이 좋다.

### E. 색인 모니터링 루틴 (주간)
서치어드바이저에서 볼 것 3가지 — 리포트 → 색인 현황 (색인 페이지 수 추세가 발행량과 같이 늘어야 정상), 리포트 → 수집 현황 (수집 오류·차단 발생 여부), 검증 → 웹 페이지 최적화 (항목별 통과 여부). 색인 수가 정체되면 사이트맵/RSS 재수집 요청부터.

### F. 도메인 정합
서치어드바이저 등록 도메인이 wecircle.co.kr 인지 확인 (구 medimap-blog-phi.vercel.app 이 별도 등록돼 있으면 혼선). canonical 은 이미 wecircle.co.kr 로 통일돼 있어 (Round 90~102) 코드 측은 정상.
