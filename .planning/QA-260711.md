## E. DB 무결성 (내가 대신 돌려줄 수 있음)

> Supabase SQL Editor에 붙여넣거나, **"E 확인해줘"** 하시면 제가 MCP로 실행해 드립니다.

E-1. 상품 시딩
```sql
SELECT market, lang, status FROM tenant_products WHERE tenant_id=12 ORDER BY lang;
```
   - **[정상]** en/ja/zh-Hant 3행, 전부 status=active.

E-2. 해외 키워드 + 게이팅
```sql
SELECT count(*) FROM keywords WHERE tenant_id=12 AND market='overseas';           -- 6
SELECT count(*) FROM keywords WHERE market='overseas'
  AND EXISTS (SELECT 1 FROM tenant_products p
    WHERE p.tenant_id=keywords.tenant_id AND p.market=keywords.market
      AND p.lang=keywords.lang AND p.status='active');                            -- 6
```
   - **[정상]** 둘 다 6.

E-3. 언어 스코프 RPC
```sql
SELECT (SELECT coalesce(sum(total),0) FROM citation_market_trend(30,'ko')) AS ko,
       (SELECT coalesce(sum(total),0) FROM citation_market_trend(30,'en')) AS en;
```
   - **[정상]** ko>0, en=0 (측정 전).

E-4. 국내 백필(회귀 안전)
```sql
SELECT count(*) FILTER (WHERE lang='ko' AND market='domestic') AS ko, count(*) AS total FROM keywords;
```
   - **[정상]** 기존 국내 키워드는 ko/domestic (해외 6개 제외하고 전부).
