# AEO/GEO 전략 — 메디맵 도메인 인용 매커니즘

작성: 2026-05-04 · Phase 6.6 동반 문서.

이 문서는 Phase 6.6 의 발행 추적 시스템이 어떤 가설 위에 서있는지 명시한다.
AEO(Answer Engine Optimization) / GEO(Generative Engine Optimization) 의 진짜 KPI 와,
그 KPI 를 끌어올리기 위해 메디맵이 따라야 할 채널 우선순위 + 자동화 정책을 정리한다.

---

## 1. AI 검색엔진은 무엇을 인용하는가

Perplexity / OpenAI (ChatGPT Search) / Gemini (Google AI Overviews) / Claude (web_search) 가 응답에 cite 하는 URL 의 공통 특징:

| 신호 | 가중치 | 메디맵 운영자가 통제 가능? |
|---|---|---|
| **권위 도메인** (gov/edu/학회/대중 미디어) | 매우 높음 | 간접 — 보도자료/기고로 노출 |
| **Schema.org 구조화 데이터** (FAQPage, MedicalProcedure) | 높음 | ✅ 자사 홈페이지 직접 통제 |
| **콘텐츠 신선도** (최근 6개월) | 높음 | ✅ 정기 발행 |
| **백링크 도메인 권위** | 높음 | 간접 — PR/제휴 |
| **명확한 Q&A 구조** | 중간 | ✅ FAQ 콘텐츠 |
| **모바일 적합성 / Core Web Vitals** | 중간 | ✅ 자사 홈페이지 |
| **저자 명시 (E-E-A-T)** | 중간 | ✅ 의사명/경력 노출 |
| **정확한 사실 + 출처 인용** | 중간 | ✅ Reference Library RAG |

**결론**: 자사 통제 영역(자사 홈페이지/네이버 블로그) 에서 schema 와 신선도를 100% 잡고,
권위 도메인(헬스조선/메디게이트/학회) 에는 PR + 기고로 침투하는 것이 표준 전략.

## 2. 메디맵 권장 채널 우선순위

### Tier 1 — 자사 통제 (즉시 실행, 가장 ROI 높음)
1. **자사 홈페이지** (medimap.kr 등)
   - JSON-LD FAQPage 스키마 필수 (메디맵 시스템이 schema_org 채널로 이미 생성)
   - 의사 페이지에 `Person` schema + 자격증/경력 markup
   - 시술 페이지에 `MedicalProcedure` schema (`description`, `usesDevice`, `bodyLocation`)
   - 모바일 LCP < 2.5s, CLS < 0.1
2. **네이버 블로그** (메디맵 운영 계정)
   - 한국 검색 노출 + 네이버 자체 AI(Cue:) 활용
   - 모바일 페이지 (m.blog.naver.com) 가 cite 되기 쉬움 — 정규화 시 데스크톱 도메인으로 통합 (citation.py 가 처리)
   - 발행 직후 네이버 인덱싱이 빠름 (수 시간)

### Tier 2 — 권위 도메인 (PR/기고)
3. **헬스조선** (health.chosun.com) — 도메인 권위 매우 높음. 보도자료/칼럼 기고 가능
4. **코메디닷컴** (kormedi.com) — 헬스 미디어. PR 송고 + 칼럼 가능
5. **메디게이트** (medigate.net) — 의료 전문지. 의사 칼럼 기고
6. **청년의사** (docdocdoc.co.kr) — 의료 트렌드. 인터뷰/기고
7. **의협신문** (doctorsnews.co.kr) — 협회지. 의료법 안전한 채널

### Tier 3 — 추가 노출
8. **티스토리** (자체 운영 시) — 검색 노출은 약하지만 백링크 자산
9. **네이버 플레이스** — 위치 기반 검색에서 cite 됨. 정보 100% 채우기
10. **유튜브** — 트랜스크립트가 cite 됨 (특히 Gemini)
11. **Threads/Instagram** — 직접 cite 는 낮지만 백링크 + 도메인 신호

### Tier 4 — 최상위 권위 (장기)
12. **보건복지부 / 식약처 보도자료 인용** — 직접 제출 불가, 기자 PR 필요
13. **안과학회 / 의학회 학술지** — 의사가 논문/칼럼 게재
14. **위키피디아 의료 항목** — 출처로 자사 홈페이지 등재 (기여)

## 3. "자동 발행" 의 진짜 의미 — 정책 stance

### 사용자 요구
"콘텐츠를 자동 발행하고, 어디에 발행했는지 추적하는 페이지를 만들어줘."

### CLAUDE.md 의 No auto-posting 원칙
> 외부 플랫폼(네이버 블로그/티스토리/인스타) 자동 게시 금지. 출력은 클립보드/파일로만.

### 충돌 해석 — Phase 6.6 의 선택
**완전 자동화(외부 플랫폼 직접 POST) 는 아래 이유로 채택하지 않는다:**

1. **계정 정지 리스크**
   - 네이버 블로그: 자동 게시 시 스팸 분류 + 계정 정지 사례 다수. 공식 API 는 2018년 폐쇄됨.
   - 티스토리: API 가 있지만 광고/마케팅 자동화는 ToS 위반 리스크.
   - 인스타: 비즈니스 API 만 게시 가능, 일반 계정 자동 게시는 차단.

2. **AEO 효과 없음 (오히려 -)**
   - AI 가 cite 하는 권위 도메인은 모두 **에디터 검수가 필수** — 자동 송고 거부.
   - 자동 게시된 다량 콘텐츠는 spammy signal 로 도메인 권위 ↓.

3. **의료법 리스크**
   - 자동 게시는 사후 수정 어려움 → 의료법 위반 시 광고 정지 + 행정처분.
   - 메디맵 시스템의 9개 룰 린터를 통과해도 컨텍스트(시술 설명 + 가격 동시 노출 등)는 사람이 판단.

4. **사용자 시간 절약 ≠ 발행 자동화**
   - 진짜 시간 소모는 "콘텐츠 작성 + 의료법 체크" → 메디맵이 이미 자동화.
   - 발행 자체는 90초/건 — 자동화 ROI 가 없음. 게다가 사람이 한 번 보면 명백한 오류 잡힘.

### Phase 6.6 의 절충안
- **콘텐츠 생성**: 메디맵 시스템이 자동 (LLM + 의료법 린터 + 자동 큐).
- **외부 발행**: 사용자가 수동 (복사 → 외부 에디터 → 발행 버튼). 90초.
- **추적**: 시스템이 자동 (URL 등록 → AI 응답의 cited_urls 매칭 → 인용률 측정).

이게 **AEO 효과 동일 + 정책 안전 + 시간 거의 동일** 한 절충점.

만약 사용자가 진정 "외부 플랫폼 직접 POST" 를 원하면:
- 채널을 좁혀 1-2개만 (자사 홈페이지 CMS + 네이버 블로그) 우선.
- 각 채널마다 별도 인증/오류 처리/Rate limit 설계 필요.
- CLAUDE.md 의 No auto-posting 항목을 "사용자 명시 채널만 허용" 으로 갱신 필요.
- 별도 phase (Phase 7) 로 분리 — 인증 OAuth + 게시 API + 실패 재시도 + 의료법 사후 차단 등 스코프 큼.

## 4. 발행 추적의 진짜 KPI

Phase 6 까지의 KPI: **"tenant 브랜드명이 AI 응답에 멘션되는 비율"** (mention_share)

Phase 6.6 의 KPI: **"tenant 가 발행한 URL 이 AI 응답에 cite 되는 비율"** (citation_rate)

| 멘션 vs 인용 | 멘션 (Mention) | 인용 (Citation) |
|---|---|---|
| 신호 | 본문 텍스트에 브랜드명 등장 | 응답이 URL 을 출처로 cite |
| 통제 가능성 | 중간 — 브랜드 인지도 + 학습 데이터 | 높음 — 발행 + schema + 권위 |
| AEO 의미 | 인지도 지표 | **인용도 지표 (진짜 AEO KPI)** |
| 측정 방법 | NER + 정규화 | URL 정규화 매칭 (이 phase) |

따라서 measurement_tab 의 mention_share 와 publication_tab 의 citation_rate 는 동시에 봐야 한다.
- mention_share 만 ↑ = 브랜드 인지도는 좋은데 AI 가 우리 글을 안 본다 (PR/SEO 부족)
- citation_rate 만 ↑ = 우리 글은 cite 되는데 브랜드 자체는 알려지지 않았다 (콘텐츠 톤이 자사 명시 부족)
- 둘 다 ↑ = AEO 성공

## 5. Phase 6.6 시스템 사용 워크플로 (메디맵 운영자)

1. **콘텐츠 발행 → 통합 발행** 에서 키워드별 4채널 콘텐츠 생성 (의료법 통과)
2. **발행 이력** 의 콘텐츠 카드 → 본문 복사 → 네이버 블로그/자사 홈페이지에 게시
3. 게시 직후 카드의 **📍 어디에 발행했어요** 폼에 채널 + URL 입력 → Publication INSERT
4. (병행) **인사이트 → 측정** 에서 키워드별 일일 수집 (Phase 4 ~ 6 기능)
5. 매주 1회 **콘텐츠 발행 → 발행 현황** 의 **🔄 AI 인용 매칭 갱신** 클릭
6. KPI 확인:
   - **인용률** (총 발행 대비 cite 된 비율) — Tier 1 자사 채널부터 30% 목표
   - **누적 인용 수** — 채널별로 어디서 cite 되는지 분포 확인
7. 인용 안 된 발행물은 다음 액션:
   - 자사 홈페이지: schema 검사 → 백링크 부족 → PR 송고 우선순위
   - 네이버 블로그: 키워드 매칭 약함 → 제목/도입부 재작성
   - 보도자료: 권위 매체 cite 부족 → Tier 2 매체에 후속 송고
