## 🔴🔴 세션 최대 교훈
1. **스코프 버그 2패턴**: ① 페이지는 `scope` 보내는데 **API가 안 읽음**(competitors `trends/route.ts` — `searchParams.get('scope')` 자체가 없었음) ② **서브컴포넌트가 scope를 아예 미전달**(`TrendAnalysisCard`가 tenantId·days만 받고 scope 구독/전달 없음). 스코프 UI만 있고 데이터에 안 걸리면 EN/JA/ZH 전부 동일 → 반드시 **페이지 전달 + API 필터 둘 다** 확인.
2. **키 매핑(재확정)**: 측정 `keywords.lang` = en/ja/ko/**zh-Hant** → `scopeToLang`/`scopeToKwLang`(zh→zh-Hant). 콘텐츠 `generated_contents.lang` = en/ja/ko/**zh-Hans** → `scopeToContentLang`(zh→zh-Hans). 섞으면 ZH가 0으로 샘.
3. **함정 ED 여전**: 대형/신규 파일 Write·Edit 직후 샌드박스 마운트 절단(EOF 에러). 호스트 파일은 무결. 게이트는 **git HEAD 재구성(\r\n→\n 정규화) + 편집 재적용(anchor assert) → /tmp esbuild**. 신규 파일은 /tmp에 전문 재기록.
4. **냉정한 ROI 판단**: 이미 리디자인된 성숙 화면(대시보드=Round 119 3존 재설계, 콘텐츠관리·경쟁사=풀폭·mb-6)은 통짜 재디자인 이득 작음 → 여백 압축만. saas-tracking 언어스코프는 자사 B2B(전부 ko)라 의미 약함 → 스코프+빈상태 안내로 미래 대비만.
