## 🔴🔴 세션 최대 교훈
1. **esbuild≠tsc 재확인(2회 더).** guides.ts `data.aeo` possibly-undefined(reports), 그리고 여러 build. esbuild PASS해도 Vercel tsc fail. 빌드-크리티컬 변경은 **격리 tsc(git-HEAD 재적용) 또는 Vercel 빌드 Ready 실측**. py 파일은 git-HEAD 재적용 py_compile.
2. **Next redirect()는 fetch로 검증 불가.** `/clinics`→`/guides` 301이 `fetch(redirect:'manual')`엔 200으로 보였으나 **실브라우저 네비게이션은 정상 301**(RSC redirect). 리다이렉트 검증은 브라우저 navigate로.
3. **Postgres 정규식 non-greedy 신뢰 금지.** FAQ 백필 시 `(.*?)</p>`가 greedy처럼 전체를 먹음 → `regexp_split_to_table(body,'</p>')`로 **먼저 분할 후** 조각별 추출. Python `re`는 non-greedy 정상.
4. **fetch()는 Next 주입 hreflang 링크를 자주 누락.** canonical은 잡히나 `<link hreflang>`은 0으로 보임 → **document.head(실브라우저)로 검증**.
5. **auto-publish cron: daily_count=1 + ko 키워드 낮은 id → 해외 절대 생성 안 됨.** 해외 볼륨 병목의 실체. market_only 필터 + 전용 워크플로로 해소.
