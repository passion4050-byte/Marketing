## 🔴🔴 세션 최대 교훈 3가지
1. **OneDrive 안의 `.git` = gc 무한 프롬프트 루프.** 커밋 시 git auto-gc가 `.git/objects/00` 삭제를 시도 → OneDrive 잠금과 충돌 → "Deletion of directory failed. Should I try again?(y/n)"가 256개 폴더마다 무한 반복. `gc.auto 0`으로도 완전히 안 막힘. **확실한 회피 = OneDrive 트레이 → 동기화 일시중지(2h) 후 push.** 근본해결 = repo를 OneDrive 밖(예: `C:\dev\Marketing`)으로 이동. 탈출 = Ctrl+C 또는 창 닫기(커밋 오브젝트는 이미 기록됨, 무손상).
2. **client fetch race — scoped 컴포넌트 필수 가드.** 초기 props 없는 client 컴포넌트(리더보드)는 mount 시 scope='all'로 먼저 fetch(느린 JS 라우트) → setScope(readScope())로 scoped fetch(빠른 RPC). **취소 가드 없으면 느린 all 응답이 빠른 scoped 응답을 덮어씀** → all 데이터 표시 버그. 해결 = useEffect cleanup `cancelled` 플래그 or `reqSeq` ref로 stale 응답 무시. (citations/competitors 페이지도 seq 가드 적용.)
3. **workflow 파일 push는 `workflow` OAuth scope 필요.** git 토큰에 workflow scope 없으면 `.github/workflows/*.yml` push가 `! [remote rejected] ... refusing to allow an OAuth App to create or update workflow`로 거부됨. 회피 = 워크플로만 빼고 push(`git reset --soft HEAD~1; git restore --staged <yml>`) 후, 워크플로는 **GitHub 웹 Add file로 추가**(웹 커밋은 scope 불필요).
