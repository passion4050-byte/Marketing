## 🔴 함정 EF (치명) — 호스트 파일 동기화

이 세션 최대 시간 낭비. **에이전트 파일 도구(Edit/Write)로 편집한 내용이 사용자 실디스크(git 작업트리)에 안 닿는 경우가 있음.**

- 관찰: 새 파일(Write로 생성)은 실디스크로 동기화됨. 그러나 기존 추적 파일의 수정은 사용자 `git status`에 "nothing to commit"으로 안 잡힘(`git diff` 비고, `ls-files -v`는 `H` 정상). Get-Content로 보면 실파일엔 편집이 있는데 git이 변경을 못 봄.
- **우회 해법(검증됨):** 수정본을 **새 파일**(`_fix`, `_fix2~6`, `_patch134`)로 만들고 → 사용자가 `Copy-Item _fixN\X 원본경로\X -Force` 덮어쓰기 → `git add` → commit → push. 이 경로로 middleware·page·SidebarShell·AdminShell 전부 반영·배포 성공.
- 보조: `git update-index --no-skip-worktree --no-assume-unchanged <file>` 후 add. `.git/index.lock` stale → 사용자 로컬 `Remove-Item ...\.git\index.lock`.
- push는 항상 사용자 로컬 PowerShell. 빌드 게이트: /tmp 복사 후 `npx --yes esbuild --loader:.tsx=tsx <f> --outfile=/dev/null` exit 0.
