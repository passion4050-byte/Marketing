## 2. 기술 스택

- **Backend / Pipeline:** Python 3.11+, `openai` / `anthropic` / `google-genai` / Perplexity REST
- **Embedding:** `text-embedding-3-small` (OpenAI)
- **Vector DB:** `chromadb` (로컬 파일)
- **Crawling:** `httpx` + `trafilatura`
- **DB:** SQLite (Streamlit) + Supabase Postgres (medimap-blog)
- **Scheduler:** APScheduler
- **Dashboard:** Streamlit (테넌트 + 어드민)
- **Stats:** `scipy.stats`, `pymannkendall`
- **NER:** `kiwipiepy` + 룰베이스
- **Logging:** `structlog`
- **Test:** `pytest`
- **Frontend:** Next.js 14 SSG (medimap-blog) + Tailwind + shadcn 톤

## 4. 핵심 컨벤션 (반드시 유지)

1. **Multi-tenant from day 1** — 모든 테이블 `tenant_id` FK, 격리 강제
2. **Compliance 강제** — 의료법 린터를 모든 콘텐츠 생성 경로에 강제. 우회 경로 금지
3. **Cost guardrail** — `MAX_DAILY_USD`, `MAX_CONTENT_GEN_PER_DAY` 사전 체크
4. **No auto-posting** — 외부 플랫폼 자동 게시 금지. 출력은 클립보드/파일로만
5. **Korean-first** — UI/콘텐츠/룰 한국어. 영어는 코드 식별자에만
6. **Async I/O** — LLM 호출, HTTP, DB는 가능한 비동기
7. **No mocking DB in tests** — SQLite 메모리 DB 실제 사용. LLM은 모킹 OK
8. **Streamlit stale module cache 가드** — `hasattr(Model, "field")` 또는 `try/except ImportError`
9. **Design-only changes** — 디자인 작업 시 기능 로직 절대 손대지 말 것
10. **Cross-site design sync** — 토큰 4 파일 동시 갱신 + SVG `<linearGradient>` stop-color 별도 체크
11. **Token-first components** — `brand-*` / `accent-*` 토큰만 사용. `#hexcode` 직접 삽입 금지

## 7. 운영 메모 (배운 교훈)

### Streamlit Cloud
- 재배포 후 `sys.modules` 캐시로 신규 ORM 컬럼/모델이 누락된 채 실행될 수 있음 → `hasattr` 가드 필수, 완전 해소는 reboot
- SQLite 휘발 대응 → `seed_if_empty()` 부트스트랩 시 호출
- Slug `admin` 은 reserved word → `blogkey-adm` 으로 우회

### Vercel
- 함수 타임아웃 Hobby 10s 한도 → `connect_timeout=5` + 503 명시화, silent fallback 금지
- UTC 환경이므로 KST 표시는 `src/lib/datetime.ts` helper 경유
- `next/og` ImageResponse Windows 빌드 우회 → OG/favicon 라우트 `force-dynamic` 적용
- Server action `cookies.set + redirect` stuck → API Route + `window.location.assign` 패턴
- WAF 가 Lighthouse 차단 가능, PSI API 무인증 quota=0
- `next/script` 전략은 **항상 `afterInteractive`** — `lazyOnload` 시도했으나 작은 스크립트라 main thread idle 진입을 늦춰 TBT/FCP 회귀 → 되돌림

### 데이터 / RAG
- 네이버 블로그 fetch — Streamlit Cloud(미국 GCP) 에서 데스크탑 응답 축소 → 모바일 페이지 + 모바일 UA 우회
- RAG raw_text 정제는 디스플레이 시점에만 — 인덱서 단계 정제하면 청크 hash 깨져 중복 차단 깨짐

### 자동화
- `tools/deploy_github.py` — GitHub Device Flow OAuth → private 리포 생성 → master→main 리브랜드 → 첫 푸시 → 토큰 strip
- 일반 재배포는 `git push origin main` 만으로 충분
- `commit + push` 까지가 한 묶음 — "라이브 확인 가능" 보고 전 ahead 상태 0 확인 필수
