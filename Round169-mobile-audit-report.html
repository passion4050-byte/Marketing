증거LoginForm.tsx:63-79 — autoCapitalize/autoCorrect/name/inputMode 전부 없음 → iOS가 발급 아이디 첫 글자를 대문자로 변환. text-sm(14px) → 포커스 시 확대. name 부재로 키체인 자동입력 실패하는데 비밀번호는 랜덤 10자라 외울 수 없음. 세션은 7일 고정, 활동 기반 갱신 없음.
담당자 영향원장님이 물어본 그 순간 로그인 화면이 뜨고, 대문자로 바뀐 아이디가 계속 튕기고, 랜덤 비번은 기억에 없음 → 그 자리에서 근거 제시 실패. 반복되면 포털을 아예 안 엶.
수정안autoCapitalize="none" autoCorrect="off" spellCheck={false} name="username" + text-base py-3(16px). 만료 3일 이내면 쿠키 재발급(sliding session), 최소 30일로 연장.
감사 방법 — 소스 정적분석(v1·v2 전 파일) + 라이브 계측(파트너 글 실측: 문서 11,601px·18.2스크린, TTFB 114ms/load 1.4s/65KB, 탭 타겟 14개 미달, 가로 오버플로 0). 페르소나 4명 × 4관점.
계측 한계 — 데스크톱 Chrome 창 최소 폭 제한으로 뷰포트는 491px까지만 축소됨(Tailwind 모바일 브랜치 sm:640 미만이라 CSS 경로는 실제 모바일과 동일). 375px 수치는 소스 기반 계산값.
다음 단계 — 이 리포트에서 구현할 항목을 지정해 주시면 그대로 코드로 반영합니다. 권장 순서: P0 11건 → P1 중 재발방지형(.admin-table-wrap 적용, px-8 일괄 치환, overline 유틸) → 나머지.
