# 커버 이미지 루틴 (국내·해외 공통)

## 원칙 (CLAUDE.md 이미지 규칙 상속)
- **무인물** — 사람 얼굴/신체 금지 (초상권·의료광고 리스크)
- **무한글/무텍스트** — 이미지 안에 글자·워터마크·브랜드명 금지. (특히 해외 en/ja/zh 페이지에 한글 텍스트가 박힌 커버 절대 금지)
- **글 맥락** — 주제와 연결 (예: 시력교정 → 광학/렌즈/눈 모티프)
- **시네마틱 톤** — 16:9, 딥톤, 브랜드 블루(#1B68FF) 계열
- **cover_image_alt** — 각 언어로 현지화 (SEO/접근성)

## 소스별 규칙
1. **국내 블로그(domestic)** — 파이프라인이 실사/생성 이미지를 Supabase `post-images` 버킷에 업로드.
   - ⚠️ 현재 국내 커버 다수가 한글 제목·병원 브랜드가 **박혀** 있음 → **해외 재사용 금지**.
2. **해외 가이드(overseas en/ja/zh)** — 텍스트 없는 커버만.
   - 현 상태: `smile-lasik-in-korea` 3개국(id 203/205/206) = **광학/렌즈 모티프 시네마틱 SVG data-URI** (무텍스트, 네트워크 의존 0 → 데모에서 절대 안 깨짐).
   - 향후 실사 전환 시: 무텍스트·무인물 실사를 `post-images` 버킷에 업로드하고 그 URL로 교체. SVG 커버는 폴백으로 유지.

## 발행 전 검증 체크(3항목)
- [ ] 커버가 실제 렌더되는가 (빈 박스/깨진 링크 아님)
- [ ] 이미지에 한글/워터마크/인물 없는가
- [ ] 주제 맥락에 맞는가 (진료과/시술)

## SVG 커버 생성 방법 (재현)
`tools`나 세션에서 Python `urllib.parse.quote(svg, safe="")` 로 인코딩 → `data:image/svg+xml,{enc}` 를
`generated_contents.cover_image_url` 에 UPDATE. 렌즈/광학 모티프 = 동심원 + radial glow + 딥 네이비→#1B68FF 그라디언트, 텍스트 없음.
