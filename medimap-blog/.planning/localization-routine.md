# 언어별 현지화 루틴 (해외 콘텐츠)

## 대원칙: 번역이 아니라 현지화(Transcreation)
한국어 원문을 그대로 옮기지 않는다. **각 언어로 네이티브가 처음부터 쓴 것처럼** — 정서·문화·신뢰 트리거·대화체·구매 결정 동인을 시장별로 재구성한다.
생성 파이프라인의 writer 단계는 KO→X 번역이 아니라 **언어별 네이티브 프롬프트로 각각 생성**한다.

## 시장별 톤 & 문화 코드

### 🇺🇸/글로벌 English
- **문체**: 명료·간결, "you" 직접 화법, 과장(hype) 금지, 근거·수치 중심.
- **신뢰 트리거**: 의사 자격/장비/영어 응대, 투명한 가격대, 정직한 리스크 고지(FTC 감성).
- **결정 동인**: 결과 예측가능성 + 여행 편의(스케줄·회복기간·통역).
- **피할 것**: 단정적 효능 보장, 최상급 남발("the best").

### 🇯🇵 日本語
- **문체**: です・ます체 정중, 부드럽고 배려적, 단정 회피(「〜と言われています」「個人差があります」).
- **신뢰 트리거**: 안심(안전·위생·애프터케어), 구체적 절차 설명, 정중한 예약 안내.
- **결정 동인**: 불안 해소 > 가격. 세심한 사전/사후 케어, 트러블 시 대응.
- **피할 것**: 과도한 직설·압박형 CTA, 과장 광고 뉘앙스.

### 🇨🇳 中文(简体·본토 기준)
- **문체**: 실용·직접, 结果 중심, 具体的 수치/전후 비교/후기 선호.
- **신뢰 트리거**: 가성비(性价比), 실제 효과·리뷰, 절차 효율(비자·통역·일정), 병원 규모/의사 경력.
- **결정 동인**: 效果 + 性价比 + 편의(예약·결제·이동).
- **주의**: 简体(본토) vs 繁體(홍콩·대만)는 어휘·정서 다름. 현재 zh-Hans=본토. 繁體 필요 시 별도.

## 공통 규칙
- 통화·단위·예시는 현지 감각으로(예: KRW 병기, 필요 시 USD/JPY/CNY 참고치).
- 의료법·현지 광고규정 준수(효능 단정/최상급/비교광고 회피)는 언어 불문 유지.
- 표·FAQ·가격대 등 AEO 구조는 유지하되 **표현은 현지화**.

## 발행 전 QA 체크(언어별)
- [ ] 번역투(직역 흔적) 없는가 — 네이티브가 읽어 어색하지 않은가
- [ ] 해당 시장 신뢰 트리거가 반영됐는가(일=안심 / 중=가성비·결과 / 영=근거·투명성)
- [ ] CTA 톤이 시장 정서에 맞는가(일=정중 / 중=직접 / 영=간결)
- [ ] 의료법·현지 광고규정 통과
